# النحو والتراكيب

Sentence frames, particles and connectors copied from English or French.
Ordered by how often each shows up in modern writing. Severity and the
`الاستثناء` lines matter: several of these constructions are correct Arabic
in other uses.

### SYN-001 · تمّ + مصدر
- **العلامة:** تمّ / يتمّ / سيتمّ + مصدر (تم إرسال، يتم تنفيذ، سيتم إرجاع)
- **الأصل:** passive "was sent / is done / will be returned"
- ✗ تمّ إرسال الرسالة → ✓ أُرسلت الرسالة
- ✗ ثم سيتمّ إرجاعكم إليه → ✓ ثم إليه تُرجَعون
- **الحكم:** 🔴 فعل مساعد يحمل مصدرًا، والعربية تبني الفعل نفسه للمجهول
- **المصدر:** ص 45، 60

### SYN-002 · من خلال / عبر للوسيلة
- **العلامة:** من خلال / عبر + وسيلة أو دليل
- **الأصل:** through, via
- ✗ يُستدلّ على ذلك من خلال تلاصق الوحدات السكنية → ✓ يُستدلّ على ذلك بتلاصق المساكن
- ✗ أشكره لما أثاره عبر مقاله من قضايا → ✓ أشكره لما أثاره بمقاله من قضايا
- **الحكم:** 🔴 العربية تدلّ على الآلة والسبب بالباء
- **الاستثناء:** المعنى المكاني على حقيقته سليم (نظر من خلال النافذة، عبَر النهر).
- **المصدر:** ص 54

### SYN-003 · خاصّتي / الخاصّ بك للملكية
- **العلامة:** اسم + خاصّتي / خاصّتك / خاصّته، الخاصّ بي / بك / به
- **الأصل:** my / mine (ملكية بكلمة منفصلة)
- ✗ القلب خاصّتي → ✓ قلبي
- ✗ أدخل كلمة المرور الخاصة بك → ✓ أدخل كلمة مرورك
- **الحكم:** 🔴 الملكية في العربية ضمير متصل بالاسم، لا كلمة مستقلة بعده
- **الاستثناء:** الخاصّ في مقابل العامّ سليم (حسابه الخاصّ لا حساب الشركة).
- **المصدر:** ص 24

### SYN-004 · فقط للحصر
- **العلامة:** فقط، ولا سيما مقحمةً قبل الفعل (أنا فقط أقول، يُلبس فقط من قبل)
- **الأصل:** only
- ✗ أنت فقط منذر → ✓ إنما أنت منذر
- ✗ يخدعون أنفسهم فقط → ✓ وما يخدعون إلا أنفسهم
- ✗ أنا فقط أقول الحقيقة → ✓ لا أقول إلا الحق
- **الحكم:** 🟡 العربية تقصر بـ إنما وبـ ما/لا … إلا وبالتقديم، و«فقط» قليلة في نثرها القديم ثم غلبت بالترجمة
- **الاستثناء:** «فقط» في آخر الكلام بعد عدد أو مقدار (عشرة دنانير فقط) أخفّ؛ لا تعلّمها إلا إذا تكررت.
- **المصدر:** ص 61

### SYN-005 · بعض + اسم للتنكير
- **العلامة:** بعض + جمع أو اسم جنس (بعض الناس، بعض الكتب، بعض الوقت، بعض الماء، بعض المال)
- **الأصل:** some
- ✗ أعلّمك بعض الكلمات → ✓ أعلّمك كلماتٍ
- ✗ سقاه بعض الماء → ✓ سقاه ماءً
- ✗ سكنتُ بمكة بعض الوقت → ✓ سكنتُ بمكة وقتًا
- **الحكم:** 🟡 التنوين وحده يدل على التنكير؛ «بعض» صحيحة لكنها غلبت لمطابقتها some
- **الاستثناء:** إذا أُريد التبعيض حقًّا (أخذ بعضهم دون بعض) فهي في موضعها.
- **المصدر:** ص 58–59

### SYN-006 · لـ / لمدة قبل المدة
- **العلامة:** لـ / لمدة + مدة زمنية (لثلاث ليالٍ، لسنوات عديدة، لمدة يومين)
- **الأصل:** for (three nights, years)
- ✗ أقام عندهم لمدة يومين → ✓ أقام عندهم يومين
- ✗ لن تتمكن من التحدث إلى الناس لثلاث ليالٍ → ✓ ألّا تكلّم الناس ثلاث ليالٍ
- **الحكم:** 🔴 المدة في العربية ظرف منصوب بلا حرف، واللام ترجمة for؛ ولا تكفي إجازة بعض المعاجم الحديثة
- **المصدر:** ص 51

### SYN-007 · النسبة مكان الإضافة (الرئيس المصري)
- **العلامة:** ال + منصب أو كتاب أو مكان + ال + نسبة إلى بلد أو فرقة (الرئيس المصري، الطبقات الحنبلية، شبه الجزيرة العربية)
- **الأصل:** the Egyptian president, the Arabian Peninsula
- ✗ الرئيس المصري → ✓ رئيس مصر
- ✗ الطبقات الحنبلية → ✓ طبقات الحنابلة
- ✗ شبه الجزيرة العربية → ✓ جزيرة العرب
- **الحكم:** 🔴 الرئاسة والتبعية تُؤدَّى بالإضافة؛ والنسبة لا تفيد إلا أن الرئيس مصريّ، أيًّا كان ما يرأسه
- **الاستثناء:** النسبة وصفًا لا رئاسةً سليمة (طبيب مصري، فقيه حنبلي).
- **المصدر:** ص 50

### SYN-008 · الكاف للصفة (كمعلّم)
- **العلامة:** كـ + اسم دور أو صفة (كمعلّم، كعضو، كرئيس)
- **الأصل:** as / en tant que
- ✗ عمل كمعلّم في المدرسة → ✓ عمل معلّمًا في المدرسة
- ✗ كعضو في اللجنة أرى أن … → ✓ وأنا عضو في اللجنة أرى أن …
- **الحكم:** 🟡 الكاف للتشبيه، والدور يُؤدَّى بالحال أو بـ«بصفته»؛ نقله المؤلف عن الهلالي ولم يفصّل فيه في الصفحات المقروءة
- **المصدر:** ص 29

### SYN-009 · كثرة سـ / سوف
- **العلامة:** سـ / سوف + مضارع والسياق يدل على الاستقبال (بعد إن وإذا ولعلّ، في الوعد والوعيد والنتائج)
- **الأصل:** will / shall
- ✗ ثم سيجعلكم تموتون ثم سيعيدكم إلى الحياة → ✓ ثم يميتكم ثم يحييكم
- ✗ يؤمنون أنهم سيلقون ربهم وأنهم سيعودون إليه → ✓ يظنون أنهم ملاقو ربهم وأنهم إليه راجعون
- **الحكم:** 🟡 المضارع المجرد واسم الفاعل يدلّان على المستقبل؛ سـ وسوف صحيحتان لكنهما غلبتا لأن الإنجليزية تلزم will
- **المصدر:** ص 59–60

### SYN-010 · باستثناء / مع بعض الاستثناءات
- **العلامة:** باستثناء، مع بعض الاستثناءات، مع استثناءات قليلة، بشكل استثنائي
- **الأصل:** with the exception of, with few exceptions, exceptionally
- ✗ جاؤوا جميعًا باستثناء أحمد → ✓ جاؤوا جميعًا إلا أحمد
- ✗ ما فيه عيب باستثناء أنه سريع الكلام → ✓ ما فيه عيب غير أنه سريع الكلام
- ✗ لم تُعنَ الكتب الستة بتخريجها، مع بعض الاستثناءات → ✓ لم تُعنَ الكتب الستة بتخريجها إلا قليلًا
- **الحكم:** 🔴 أدوات الاستثناء (إلا، غير، سوى، عدا) أخصر وأعرب، وقد أزاحتها العبارة الاسمية
- **المصدر:** ص 79

### SYN-011 · عبارة مكان الأداة (إلى درجة أن، في حال)
- **العلامة:** إلى درجة أنّ، في حال (أنّ) + فعل، بالرغم من حقيقة أنّ
- **الأصل:** to the extent that, in case, despite the fact that
- ✗ يخالطنا إلى درجة أنه يسأل … → ✓ يخالطنا حتى يقول …
- ✗ في حال أنكم تبتم فهو خير لكم → ✓ فإن تبتم فهو خير لكم
- ✗ يغفر للناس بالرغم من حقيقة أنهم ظالمون → ✓ يغفر للناس على ظلمهم
- **الحكم:** 🔴 للعربية أداة واحدة لكل من هذه المعاني (حتى، إنْ وإذا، على)، والعبارة المترجمة أطول وأبعد؛ و«في حال» ظرف وُضع موضع أداة الشرط
- **المصدر:** ص 53

### SYN-012 · بالرغم من
- **العلامة:** بالرغم من، بالرغم من أنّ
- **الأصل:** malgré / in spite of
- ✗ خرج بالرغم من المطر → ✓ خرج على شدة المطر
- ✗ يغفر لهم بالرغم من ظلمهم → ✓ يغفر لهم على ظلمهم
- **الحكم:** 🟡 عدّها الكتاب من المولّد عن الفرنسية، وبديله «على» + مصدر؛ ولم يحكم في الصفحات المقروءة على «على الرغم من» و«رغم»، فلا تعلّمهما
- **المصدر:** ص 31، 53

### SYN-013 · اسم التفضيل نعتًا (الشخص الأحرص)
- **العلامة:** ال + اسم + الأفعل (الشخص الأحرص، الصاحب الأفضل، الليالي الأطول، البنات الأحسن، القادة الأكبر)
- **الأصل:** the most X N, the X-est N
- ✗ الشخص الأحرص → ✓ أحرص الناس
- ✗ الأكلة الألذّ → ✓ أطيب الطعام
- ✗ الأمهات الأكرم → ✓ أكرم الأمهات
- **الحكم:** 🔴 العربية تفاضل بإضافة «أفعل» إلى الجماعة؛ وأوضح الخطأ «الأفعل» المذكر المفرد بعد جمع أو مؤنث، وإن أجازه مجمع القاهرة
- **الاستثناء:** «الأفعل» المطابق لموصوفه للدلالة على الغاية لا على المفاضلة سليم (الأسماء الحسنى، العروة الوثقى).
- **المصدر:** ص 49–50

### SYN-014 · نحو / تجاه مع الرحمة والمشاعر
- **العلامة:** نحو / تجاه بعد رحمة، رحيم، شفقة وما في معناها
- **الأصل:** towards
- ✗ يُظهر الرحمة نحو الضعفاء → ✓ يرحم الضعفاء
- ✗ هو رحيم تجاه الناس → ✓ هو رحيم بالناس
- **الحكم:** 🔴 الفعل يتعدى بنفسه، والصفة بحرفها (رحيم بـ)، ولا موضع هنا لظرف المكان
- **الاستثناء:** لم يتناول الكتاب بعدُ «موقفه تجاه» و«المسؤولية تجاه»؛ اقترح «موقفه من» و«المسؤولية عن» بدرجة 🟡 فقط.
- **المصدر:** ص 53

### SYN-015 · ضدّ حرفَ جرّ
- **العلامة:** ضدّ + اسم بعد فعل أو مصدر (يحذّر ضدّ، المساعدة ضدّ، تحالفوا ضدّ)
- **الأصل:** against
- ✗ يطلب المساعدة ضدّ أخيه من الأمراء → ✓ يستعين بالأمراء على أخيه
- ✗ التحذير ضدّ الأخطاء قبل وقوعها → ✓ التحذير من الأخطاء قبل وقوعها
- ✗ يتعاونان ضدّ الفتّان → ✓ يتعاونان على الفتّان
- **الحكم:** 🔴 «ضدّ» اسم بمعنى المخالف لا حرف، والعربية تستعمل الحرف الذي يتعدى به الفعل (على، من)
- **المصدر:** ص 54، 65

### SYN-016 · النسبة لبيان المادة (ثوب صوفي)
- **العلامة:** اسم + نسبة إلى مادته: صوفي، خشبي، حديدي، ذهبي، فضّي، حريري
- **الأصل:** woolen, wooden, gold, silk (adjective of material)
- ✗ ثوب صوفي → ✓ ثوب صوف
- ✗ صحن خشبي / خاتم حديدي → ✓ صحن خشب / خاتم حديد
- ✗ قميص حريري / خاتم ذهبي → ✓ قميص حرير / خاتم ذهب
- **الحكم:** 🔴 بيان المادة في العربية بالإضافة أو بـ«من»، ولا تزال العامية تقول «ثوب صوف»
- **الاستثناء:** النسبة للّون أو الشبه سليمة (لون ذهبي، ملمس حريري).
- **المصدر:** ص 51

### SYN-017 · سوف لن
- **العلامة:** سوف لن، سوف لا
- **الأصل:** will not
- ✗ هم سوف لن يؤمنوا → ✓ لن يؤمنوا / لا يؤمنون
- ✗ عذابهم سوف لن يُخفَّف → ✓ فلا يُخفَّف عنهم العذاب
- **الحكم:** 🔴 «لن» تنفي المستقبل بنفسها، وزيادة «سوف» عليها نقل لـ will + not
- **المصدر:** ص 60

### SYN-018 · أو بمعنى أي
- **العلامة:** اسم + أو + اسم آخر للمسمّى نفسه
- **الأصل:** or (= that is)
- ✗ هذا البيت للحسن بن هانئ أو أبي نواس → ✓ هذا البيت للحسن بن هانئ، أي أبي نواس
- ✗ أعظم العبادة التوحيد، أو إفراد الله بالعبادة → ✓ أعظم العبادة التوحيد، أي إفراد الله بالعبادة
- **الحكم:** 🔴 «أو» للتخيير والشك فتوهم شيئين، وأداة التفسير «أي»
- **المصدر:** ص 31، 52

### SYN-019 · كلّما … كلّما
- **العلامة:** كلّما … كلّما
- **الأصل:** the more … the more / plus … plus
- ✗ كلّما اجتهدتَ كلّما نجحت → ✓ كلّما اجتهدتَ نجحت
- **الحكم:** 🔴 «كلّما» تدخل على الشرط وحده، وتكرارها في الجواب نقل للمقارنة المزدوجة
- **المصدر:** ص 31–32

### SYN-020 · بالتأكيد مكان أدوات التوكيد
- **العلامة:** بالتأكيد، بكلّ تأكيد + فعل
- **الأصل:** definitely, certainly
- ✗ ستجدهم بالتأكيد أحرص الناس على الحياة → ✓ ولتجدنّهم أحرص الناس على حياة
- **الحكم:** 🟡 العربية تؤكد في بنية الجملة (إنّ، اللام، نون التوكيد، قد)، والإنجليزية تُلحق ظرفًا؛ الظرف صحيح لكنه منقول
- **المصدر:** ص 60

### SYN-021 · جملة الصلة مكان النعت السببي
- **العلامة:** اسم + الذي/التي + ضمير يعود عليه + خبر (القرية التي أهلها ظالمون)؛ اسم + بـ + صفة (ثمار بألوان مختلفة)
- **الأصل:** whose / of + adjective (English has no نعت سببي)
- ✗ القرية التي أهلها ظالمون → ✓ القرية الظالمِ أهلُها
- ✗ ثمار بألوان مختلفة → ✓ ثمراتٌ مختلفًا ألوانُها
- ✗ قوم أفضالهم كثيرة وصدورهم رحبة → ✓ قومٌ كثيرةٌ أفضالُهم، رحبةٌ صدورُهم
- **الحكم:** 🟡 الصلة صحيحة، لكن النعت السببي أخصر وأعرب، وكاد يموت لأنه لا مقابل له في الإنجليزية؛ اقترحه ولا تخطّئ الصلة
- **المصدر:** ص 44، 55–58

### SYN-022 · أو بعد النفي
- **العلامة:** لا / لن / لم + فعل + س أو ص
- **الأصل:** not … X or Y
- ✗ لن نترك رجلًا أو طفلًا → ✓ لن نترك رجلًا ولا طفلًا
- **الحكم:** 🟡 العربية تكرر «لا» لتنفي كل واحد (لا يغادر صغيرة ولا كبيرة)؛ لكن «أو» بعد النهي واردة في القرآن (ولا تطع منهم آثمًا أو كفورًا)، فهو ترجيح لا تخطئة
- **المصدر:** ص 52

### SYN-023 · أو في التسوية
- **العلامة:** فعل + أو لم + فعل؛ … أو لا (بمعنى سواءً)
- **الأصل:** whether … or not
- ✗ سأذهب جاء أو لم يجئ → ✓ سأذهب أجاء أم لم يجئ
- ✗ إذا حذّرتهم أو لا فلن يؤمنوا → ✓ سواءٌ عليهم أأنذرتهم أم لم تنذرهم لا يؤمنون
- **الحكم:** 🟡 الجادّة في التسوية الهمزة و«أم»؛ عدّ المؤلف «أو» فيها من أثر الترجمة مع وقوعها عند بعض القدماء
- **المصدر:** ص 53، 60

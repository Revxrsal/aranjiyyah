# النحو (١): الأدوات والروابط والأزمنة

Particles, connectors, tense markers and modal verbs copied from English or
French. Noun phrases, relative clauses, word order and question forms are in
`syntax-phrases.md`. SYN IDs run across both files. Ordered by how often
each shows up in modern writing. Many of these words are sound Arabic in
other uses, so read the `الاستثناء` lines.

### SYN-001 · تمّ + مصدر
- **العلامة:** تمّ / يتمّ / سيتمّ / لا يتمّ + مصدر (تمّ إرسال، يتمّ تنفيذ، تمّ قتله)، ومعه غالبًا «من قِبَل» للفاعل
- **الأصل:** the passive: was sent, is done, was killed by
- ✗ تمّ إرسال الرسالة → ✓ أُرسلت الرسالة
- ✗ ثم سيتمّ إرجاعكم إليه → ✓ ثم إليه تُرجَعون
- ✗ الذي تمّ قتله من قِبَل طارق → ✓ الذي قتله طارق
- **الحكم:** 🔴 فعل مساعد يحمل مصدرًا، والعربية تبني الفعل نفسه للمجهول، أو تذكر الفاعل فاعلًا
- **المصدر:** ص 45، 60، 124–125، 186، 188

### SYN-002 · من خلال / عبر للوسيلة
- **العلامة:** من خلال / عبر + وسيلة أو سبب أو دليل أو مدخل
- **الأصل:** through, via
- ✗ يُستدلّ على ذلك من خلال تلاصق المساكن → ✓ يُستدلّ على ذلك بتلاصق المساكن
- ✗ أشكره لما أثاره عبر مقاله من قضايا → ✓ أشكره لما أثاره بمقاله من قضايا
- ✗ يدخلون من خلال الباب → ✓ يدخلون من الباب
- **الحكم:** 🔴 العربية تدلّ على الآلة والسبب بالباء، وعلى المدخل بـ«من»
- **الاستثناء:** النفاذ في الشيء على حقيقته سليم (نظر من خلال النافذة، عبَر النهر).
- **المصدر:** ص 54، 187

### SYN-003 · خاصّتي / الخاصّ بك للملكية
- **العلامة:** اسم + خاصّتي / خاصّته، الخاصّ بي / بك / به، و«الخاصّ» بعد اسم مضاف إلى ضمير (طريقهم الخاص، نوعه الخاص، فكرته الخاصة)
- **الأصل:** my / mine / his own
- ✗ القلب خاصّتي → ✓ قلبي
- ✗ أدخل كلمة المرور الخاصة بك → ✓ أدخل كلمة مرورك
- ✗ وفكرته الخاصة كانت ألّا يأكل … → ✓ وكان رأيه ألّا يأكل …
- **الحكم:** 🔴 الملكية في العربية ضمير متصل بالاسم، لا كلمة مستقلة بعده
- **الاستثناء:** الخاصّ في مقابل العامّ سليم (حسابه الخاصّ لا حساب الشركة).
- **المصدر:** ص 24، 99، 155، 158، 163

### SYN-004 · هناك / يوجد في صدر الجملة
- **العلامة:** هناك / كان هناك / ليس هناك / يوجد / توجد + نكرة
- **الأصل:** there is / there are
- ✗ ليس هناك ريال في المحفظة → ✓ ليس في المحفظة ريال
- ✗ كان هناك رجل قتل تسعة وتسعين نفسًا → ✓ كان فيمن كان قبلكم رجل قتل تسعة وتسعين نفسًا
- ✗ هناك قصص كثيرة كهذه → ✓ وأمثال هذه الحكايات كثيرة
- **الحكم:** 🟡 «هناك» الوجودية عربية قديمة لكنها نادرة؛ غلبت لمطابقتها there is، وأزاحت تقديم الخبر شبه الجملة، ولا النافية للجنس، وكان + نكرة
- **الاستثناء:** لا تعلّم «هناك» مفردة؛ علّم النص الذي تتوالى جمله مفتتحة بها أو بـ«يوجد».
- **المصدر:** ص 162–163، 170

### SYN-005 · عندما للشرط
- **العلامة:** عندما + مضارع في شرط عام أو مستقبل، وفي جوابه غالبًا «سوف»؛ وعندما + ماضٍ في السرد
- **الأصل:** when
- ✗ عندما يقرّر أمرًا فإنما يقول له كن → ✓ وإذا قضى أمرًا فإنما يقول له كن
- ✗ عندما أكون مريضًا فهو يشفيني → ✓ وإذا مرضتُ فهو يشفين
- ✗ عندما شرع صلاح الدين في استعادة الثغور → ✓ ولمّا قام صلاح الدين باسترجاع الثغور
- **الحكم:** 🔴 في الشرط العام والمستقبل: when تجمع الوقت والشرط، والعربية تخصّ الشرط المتوقَّع بـ«إذا» + ماضٍ؛ وفي السرد الماضي اقتراح فقط: «لمّا» لحدث يترتب عليه غيره
- **المصدر:** ص 150، 188، 190، 212

### SYN-006 · يمكن / يستطيع مقحمة
- **العلامة:** يمكنك أن، لا يمكنك، يمكن أن يكون، كيف يمكن، يستطيع أن، بإمكانك + مصدر
- **الأصل:** can, could
- ✗ يمكنك أن تجد هذا الكتاب في مكة → ✓ تجد هذا الكتاب في مكة
- ✗ لا يمكنكم أن تحصوها → ✓ لا تحصوها
- ✗ كيف يمكن أن يكون صحيحًا أن يفعل ذلك؟ → ✓ فكيف يصحّ عنه ذلك؟
- **الحكم:** 🔴 حين يصحّ المعنى بحذفها: الإنجليزية تُلحق can بالفعل، والعربية تكتفي بالفعل المجرد أو المنفي، والعامية لا تزال تقول «تلقاه في مكة»
- **الاستثناء:** إذا كانت القدرة أو الاحتمال هو المقصود (هل تستطيع حمله؟ يمكن أن يتأخر القطار) فهي في موضعها.
- **المصدر:** ص 61، 161–162، 187

### SYN-007 · أيّ + نكرة بمعنى any
- **العلامة:** أيّ + نكرة في نفي أو استفهام أو شرط (هل هناك أيّ شكّ، لا يوجد أيّ، إذا كان له أيّ، أيّ أحد)
- **الأصل:** any
- ✗ هل هناك أيّ شكّ في الله؟ → ✓ أفي الله شكّ؟
- ✗ هل عندك أيّ دليل؟ → ✓ ألك بيّنة؟
- ✗ ما عاب أيّ طعام → ✓ ما عاب طعامًا قطّ
- **الحكم:** 🔴 التنوين وحده يعمّ في النفي والاستفهام، ويُقوّى بـ«من» الزائدة (هل من، ما من) أو بـ«قطّ»؛ و«أيّ» هنا نقل لـ any
- **الاستثناء:** «أيّ» في معانيها العربية سليمة: الاستفهام عن التعيين (أيّ الكتابين تريد؟)، والشرط (أيًّا ما تدعوا)، والتعجب (أيّ رجلٍ هو!). و«أيّ أحد يفعل كذا» بابه SYN-037.
- **المصدر:** ص 147، 154، 189

### SYN-008 · بعض + اسم للتنكير
- **العلامة:** بعض + جمع أو اسم جنس (بعض الناس، بعض الكتب، بعض الوقت، بعض الماء)؛ والبعض بمعنى بعض الناس
- **الأصل:** some
- ✗ أعلّمك بعض الكلمات → ✓ أعلّمك كلماتٍ
- ✗ سقاه بعض الماء → ✓ سقاه ماءً
- ✗ وزعم البعض أنها نصّرته → ✓ وزعم بعض الناس أنها نصّرته
- **الحكم:** 🟡 التنوين وحده يدل على التنكير؛ «بعض» صحيحة لكنها غلبت لمطابقتها some
- **الاستثناء:** إذا أُريد التبعيض حقًّا (أخذ بعضهم دون بعض) فهي في موضعها.
- **المصدر:** ص 58–59، 187

### SYN-009 · كثرة سـ / سوف
- **العلامة:** سـ / سوف + مضارع والسياق يدل على الاستقبال (بعد إن وإذا ولعلّ، في الوعد والوعيد والنتائج)
- **الأصل:** will / shall
- ✗ ثم سيجعلكم تموتون ثم سيعيدكم إلى الحياة → ✓ ثم يميتكم ثم يحييكم
- ✗ يؤمنون أنهم سيلقون ربهم وأنهم سيعودون إليه → ✓ يظنون أنهم ملاقو ربهم وأنهم إليه راجعون
- **الحكم:** 🟡 المضارع المجرد واسم الفاعل يدلّان على المستقبل؛ سـ وسوف صحيحتان لكنهما غلبتا لأن الإنجليزية تلزم will
- **المصدر:** ص 59–60، 146

### SYN-010 · يجب / ينبغي للأمر والنهي
- **العلامة:** يجب أن / لا يجب أن / يجب ألّا / ينبغي أن / لا ينبغي أن، في نصح أو أمر لمخاطَب
- **الأصل:** should, must
- ✗ لا يجب أن تقول ذلك → ✓ لا تقل ذلك
- ✗ اختيارك لهم لا ينبغي أن يكون على أساس ظنّك → ✓ لا يكن اختيارك إياهم على ظنّك
- ✗ ينبغي أن يتحرّى الصواب → ✓ فليتحرَّ الصواب
- **الحكم:** 🔴 should كثيرًا ما تعني الأمر نفسه، والعربية تأمر وتنهى بالفعل ولام الأمر ولا الناهية؛ وتصحيح «لا يجب» إلى «يجب ألّا» يصلح المنطق ويُبقي القالب
- **الاستثناء:** تقرير حكم أو لزوم عام في كلام وصفي (يجب الوضوء للصلاة) سليم.
- **المصدر:** ص 205–206

### SYN-011 · فقط للحصر
- **العلامة:** فقط، ولا سيما مقحمةً قبل الفعل (أنا فقط أقول، يُلبس فقط من قِبَل)
- **الأصل:** only
- ✗ أنت فقط منذر → ✓ إنما أنت منذر
- ✗ يخدعون أنفسهم فقط → ✓ وما يخدعون إلا أنفسهم
- ✗ أنا فقط أقول الحقيقة → ✓ لا أقول إلا الحق
- **الحكم:** 🟡 العربية تقصر بـ إنما وبـ ما/لا … إلا وبالتقديم، و«فقط» قليلة في نثرها القديم ثم غلبت بالترجمة
- **الاستثناء:** «فقط» في آخر الكلام بعد عدد أو مقدار (عشرة دنانير فقط) أخفّ؛ لا تعلّمها إلا إذا تكررت.
- **المصدر:** ص 61

### SYN-012 · لكن مكان الواو والفاء
- **العلامة:** لكن / ولكن / لكنه في أول جملة تذكر الحال المقابلة أو ما ترتّب (لكن إذا، لكن لم، لكن لا أحد)
- **الأصل:** but
- ✗ إن كانت سليمة فقد أفلح، لكن إذا كانت فاسدة فقد خسر → ✓ فإن صلحت فقد أفلح، وإن فسدت فقد خسر
- ✗ من همّ بحسنة لكن لم يفعلها → ✓ من همّ بحسنة فلم يعملها
- **الحكم:** 🟡 but لازمة في الإنجليزية لعرض الحال المقابلة، والعربية تكتفي بالواو والفاء؛ كثرة «لكن» في نص علامة ترجمة
- **الاستثناء:** «لكن» للاستدراك بعد نفي أو لدفع توهّم (ما جاء زيد لكن عمرو) في موضعها.
- **المصدر:** ص 146، 149

### SYN-013 · بسبب أنّ / بسبب
- **العلامة:** بسبب أنّ / بسبب أنه؛ بسبب + مصدر حيث تكفي اللام أو «من»
- **الأصل:** because (of the fact that), due to
- ✗ قتلوه بسبب أنه رفض طاعة سليمان → ✓ إنما قتلوه لأنه خلع طاعة سليمان
- ✗ تميل رؤوسهم بسبب انخفاض الباب → ✓ يدخل منكّسًا رأسه لقِصَر الباب
- **الحكم:** 🔴 في «بسبب أنّ»: اسم للسبب مكدّس على الأداة، و«لأنّ» تكفي؛ أما «بسبب + اسم» فعربية، ويُقترح مكانها اللام أو «من» إذا كثرت
- **المصدر:** ص 187، 191

### SYN-014 · وبالتالي
- **العلامة:** وبالتالي، بالتالي
- **الأصل:** consequently, subsequently
- ✗ ليست وجهًا من وجوه الحياة الاجتماعية، وبالتالي الفكرية → ✓ … فليست كذلك وجهًا من وجوه الفكر
- ✗ وبالتالي يتطاول الأمر → ✓ فيتطاول الأمر
- **الحكم:** 🔴 ترجمة جزءًا بجزء (التالي = subsequent، والباء = ‎-ly)؛ ورابط النتيجة في العربية الفاء، ثم «لذلك» و«لهذا»
- **المصدر:** ص 97–98

### SYN-015 · بالرغم من / رغم أنّ … إلا أنّ
- **العلامة:** بالرغم من، على الرغم من، رغم + اسم؛ رغم أنّ … إلا أنّ / لكنّ
- **الأصل:** in spite of; although … nevertheless
- ✗ يغفر لهم بالرغم من ظلمهم → ✓ يغفر لهم على ظلمهم
- ✗ كان، رغم بخله، رجلًا عزيز النفس → ✓ وكان، مع بخله، أشدّ الناس نفسًا
- ✗ رغم أنّ الأردن كان مع الحلفاء، إلا أنّ عواطف الناس كانت … → ✓ ومع أنّ الأردن كان مع الحلفاء فإنّ عواطف الناس كانت …
- **الحكم:** 🟡 عدّ الكتاب «بالرغم من» من المولّد عن الفرنسية، وبديلها «على» و«مع» + اسم؛ وأوضح ما يُعلَّم الجمع بين «رغم أنّ» و«إلا أنّ» نقلًا لـ although … nevertheless
- **الاستثناء:** «على الرغم من» و«رغم» مفردتين لم يحكم عليهما الكتاب نصًّا؛ اقترح البديل ولا تخطّئ.
- **المصدر:** ص 31، 53، 172، 179، 207

### SYN-016 · نحو / تجاه مع المشاعر والمواقف
- **العلامة:** نحو / تجاه بعد رحمة، رحيم، شفقة، موقف، نظرة، شعور، كُره، تغيّر
- **الأصل:** towards
- ✗ يُظهر الرحمة نحو الضعفاء → ✓ يرحم الضعفاء
- ✗ هو رحيم تجاه الناس → ✓ هو رحيم بالناس
- ✗ تغيّر موقفه تجاهي → ✓ تغيّر عليّ
- **الحكم:** 🔴 الفعل يتعدى بنفسه أو بحرفه (رحيم بـ، تغيّر له وعليه)، ولا موضع هنا لظرف المكان
- **الاستثناء:** لم يحكم الكتاب على «المسؤولية تجاه»؛ اقترح «المسؤولية عن» بدرجة 🟡 فقط.
- **المصدر:** ص 53، 150، 173، 216

### SYN-017 · الكاف الدخيلة (كمعلّم، بوصفه)
- **العلامة:** كـ + اسم دور أو صفة (كمعلّم، كشاعر، كمسلمين، كقائد، كحجة، كردّ على، ينظر إليه كـ)؛ وبدائلها المزعومة: بوصفه، بصفته، باعتباره
- **الأصل:** as / en tant que
- ✗ عمل كمعلّم في المدرسة → ✓ عمل معلّمًا في المدرسة
- ✗ هو حسنٌ كشاعر، سيّئٌ كمعلّم → ✓ هو في الشعر حسن، وفي التعليم سيّئ
- ✗ كمسلمين لا يجوز لنا كذا → ✓ لا يجوز لنا، معاشرَ المسلمين، كذا / لا يجوز لنا كذا ونحن مسلمون
- **الحكم:** 🔴 الكاف للتشبيه لا للصفة؛ والعربية توزّع معنى as على الحال، والمفعول الثاني (أمّره عليهم)، و«في» + المجال، والاختصاص، والتعجب (أحسِن به شاعرًا)؛ و«بوصفه» بحثٌ عن أقرب لفظ لـ as يُبقي القالب
- **المصدر:** ص 29، 121، 132–134، 189

### SYN-018 · ضدّ حرفَ جرّ
- **العلامة:** ضدّ + اسم بعد فعل أو مصدر (يحذّر ضدّ، تمرّد ضدّه، حجة ضدّ، تحالفوا ضدّ)
- **الأصل:** against
- ✗ يطلب المساعدة ضدّ أخيه من الأمراء → ✓ يستعين بالأمراء على أخيه
- ✗ التحذير ضدّ الأخطاء قبل وقوعها → ✓ التحذير من الأخطاء قبل وقوعها
- ✗ فتمرّد ضدّه حبيب → ✓ فثار به حبيب
- **الحكم:** 🔴 «ضدّ» اسم بمعنى المخالف، والعربية تستعمل الحرف الذي يتعدى به الفعل (على، من، الباء)
- **المصدر:** ص 54، 65، 134، 187

### SYN-019 · لـ / لمدة قبل المدة
- **العلامة:** لـ / لمدة + مدة زمنية (لثلاث ليالٍ، لسنوات عديدة، لمدة يومين، لخمسين ليلة)
- **الأصل:** for (three nights, years)
- ✗ أقام عندهم لمدة يومين → ✓ أقام عندهم يومين
- ✗ لن تتمكن من التحدث إلى الناس لثلاث ليالٍ → ✓ ألّا تكلّم الناس ثلاث ليالٍ
- **الحكم:** 🔴 المدة في العربية ظرف منصوب بلا حرف، واللام ترجمة for؛ ولا تكفي إجازة بعض المعاجم الحديثة
- **المصدر:** ص 51، 148

### SYN-020 · حرفيًّا / فعليًّا / حقيقةً للتوكيد
- **العلامة:** حرفيًّا، فعليًّا، حقيقةً، في الحقيقة، بالفعل، ظرفًا يؤكد الجملة
- **الأصل:** literally, actually, really, in fact
- ✗ كنتُ حرفيًّا أموت من التعب → ✓ كدتُ أموت من التعب
- ✗ أنا حرفيًّا أعرف مرادك → ✓ إني لأعلمُ مرادك
- ✗ بلغ الناس أنه فعليًّا صنع الباب لهذا → ✓ بلغ الناس أنه إنما نقب الباب لهذا
- **الحكم:** 🔴 العربية تؤكد بالقسم وإنّ واللام والمفعول المطلق (صببتُ الماء صبًّا)، وتقصر بـ«إنما»؛ وإبدال «حرفيًّا» بـ«فعليًّا» أو «حقيقةً» يصلح اللفظ ويُبقي الأسلوب
- **الاستثناء:** «حرفيًّا» بمعنى لفظًا بلفظ (نقله حرفيًّا) سليمة، و«في الحقيقة» في مقابل الظاهر (في ظاهره كذا وفي حقيقته كذا) سليمة.
- **المصدر:** ص 7، 134، 169، 187

### SYN-021 · بالتأكيد مكان أدوات التوكيد
- **العلامة:** بالتأكيد، بكلّ تأكيد + فعل
- **الأصل:** definitely, certainly
- ✗ ستجدهم بالتأكيد أحرص الناس على الحياة → ✓ ولتجدنّهم أحرص الناس على حياة
- **الحكم:** 🟡 العربية تؤكد في بنية الجملة (إنّ، اللام، نون التوكيد، قد)، والإنجليزية تُلحق ظرفًا؛ الظرف صحيح لكنه منقول
- **المصدر:** ص 60

### SYN-022 · ببساطة / بكل بساطة
- **العلامة:** ببساطة، بكل بساطة (ظرفًا للجملة)
- **الأصل:** simply
- ✗ والسبب ببساطة يكمن في تراثه الصوفي → ✓ وإنما سبب ذلك تراثه الصوفي
- ✗ أنتم ببساطة تكذبون → ✓ إن أنتم إلا تخرصون
- **الحكم:** 🔴 حشو منقول من simply؛ ومعناه في العربية القصر بـ«إنما» و«ما/إنْ … إلا»، أو لا شيء
- **المصدر:** ص 92–93

### SYN-023 · باستثناء / مع بعض الاستثناءات
- **العلامة:** باستثناء، مع بعض الاستثناءات، مع استثناءات قليلة، بشكل استثنائي
- **الأصل:** with the exception of, with few exceptions, exceptionally
- ✗ جاؤوا جميعًا باستثناء أحمد → ✓ جاؤوا جميعًا إلا أحمد
- ✗ ما فيه عيب باستثناء أنه سريع الكلام → ✓ ما فيه عيب غير أنه سريع الكلام
- ✗ لم تُعنَ الكتب الستة بتخريجها، مع بعض الاستثناءات → ✓ لم تُعنَ الكتب الستة بتخريجها إلا قليلًا
- **الحكم:** 🔴 أدوات الاستثناء (إلا، غير، سوى، عدا) أخصر وأعرب، وقد أزاحتها العبارة الاسمية
- **المصدر:** ص 79، 153

### SYN-024 · عبارة مكان الأداة (إلى درجة أنّ، في حال، حقيقة أنّ)
- **العلامة:** إلى درجة أنّ، لدرجة أنّ، إلى حدّ أنّ، في حال (أنّ) + فعل، حقيقة أنّ (لحقيقة أنّ، غير حقيقة أنّ)
- **الأصل:** to the extent that; in case; the fact that
- ✗ متّعتهم وآباءهم إلى درجة أنهم نسوا الذكر → ✓ متّعتهم وآباءهم حتى نسوا الذكر
- ✗ في حال أنكم تبتم فهو خير لكم → ✓ فإن تبتم فهو خير لكم
- ✗ هل تستاؤون منا لسبب غير حقيقة أننا آمنا بالله؟ → ✓ هل تنقمون منا إلا أن آمنا بالله؟
- **الحكم:** 🔴 للعربية أداة لكلّ معنى (حتى، إنْ وإذا، أنّ وأنْ)، والعبارة المترجمة أطول وأبعد؛ و«حقيقة» لا تزيد على «أنّ» شيئًا
- **المصدر:** ص 53، 112–113

### SYN-025 · يبدو كما لو / كما لو كان
- **العلامة:** يبدو كما لو، بدا كما لو، كما لو كان، يبدو أنك (للتشبيه)
- **الأصل:** seems as if
- ✗ كان يبدو كما لو كان يكتشف عالمًا من الخيال → ✓ كأنه يكتشف عالمًا من الخيال
- ✗ تبدو كما لو كانت موعظة مودّع → ✓ كأنّ هذه موعظة مودّع
- **الحكم:** 🔴 التشبيه بالحال يُؤدَّى بـ«كأنّ»، وهي حيّة في العامية
- **الاستثناء:** «يبدو أنّ» للظنّ (يبدو أنه سافر) ليست تشبيهًا؛ إن كثرت «يبدو» فانظر MOR-007.
- **المصدر:** ص 41، 156

### SYN-026 · أو بمعنى أي / بعبارة أخرى
- **العلامة:** اسم + أو + اسم آخر للمسمّى نفسه؛ بعبارة أخرى، بكلمات أخرى، بمعنى آخر
- **الأصل:** or (= that is); in other words
- ✗ هذا البيت للحسن بن هانئ أو أبي نواس → ✓ هذا البيت للحسن بن هانئ، أي أبي نواس
- ✗ كان حزبًا وحده، أو بكلمات أخرى: كان رئيس حزب أفراده الشعب كله → ✓ كان حزبًا وحده، أي كان رئيس حزب أفراده الشعب كله
- **الحكم:** 🔴 «أو» للتخيير فتوهم شيئين، وأداة التفسير «أي» أو «والمراد / والمعنى»؛ و«بعبارة أخرى» تلطيف لـ«بكلمات أخرى» يُبقي in other words
- **المصدر:** ص 31، 52، 147

### SYN-027 · اعتاد أن للعادة الماضية
- **العلامة:** اعتاد / اعتادوا / اعتدنا أن + فعل، الذي اعتادوا أن، كما اعتيد أن يُفعل
- **الأصل:** used to, was accustomed to
- ✗ الذي اعتادوا أن يستهزئوا به → ✓ ما كانوا به يستهزئون
- ✗ اعتاد النبي أن يسكت بين التكبير والقراءة → ✓ كان رسول الله يسكت بين التكبير والقراءة
- ✗ كما اعتيد أن يُفعل لزوجها → ✓ كما كان يُفعل لزوجها
- **الحكم:** 🔴 used to علامة عادة ماضية، والعربية تؤديها بـ«كان» + مضارع، أو بالمضارع للعادة القائمة
- **الاستثناء:** «اعتاد» حين تكون العادة نفسها هي الخبر (اعتاد السهر، اعتاد البرد) سليمة.
- **المصدر:** ص 164، 166، 188

### SYN-028 · يكون رابطًا بين المبتدأ والخبر
- **العلامة:** يكون / سيكون / سوف يكون بين مبتدأ وخبر بلا معنى زمني (صاحب السيارة يكون خالد، قيل إنها تكون ابنته)
- **الأصل:** X is Y (English needs be)
- ✗ صاحب السيارة الحمراء يكون خالد → ✓ صاحب السيارة الحمراء خالد
- ✗ أول عمل يُحاسَب عليه سوف يكون الصلاة → ✓ أول ما يُحاسَب به العبد صلاته
- **الحكم:** 🔴 الإنجليزية لا تربط المبتدأ بالخبر إلا بـ be، والجملة الاسمية العربية لا تحتاج رابطًا
- **الاستثناء:** «يكون» بعد أنْ ولم وكي، أو للعادة، أو لمستقبل يقتضيه السياق، في موضعها؛ وضمير الفصل (صاحبها هو خالد) مقبول، فلا تعلّمه إلا إذا لزم كل جملة.
- **المصدر:** ص 146، 164، 186

### SYN-029 · خلال + مدة
- **العلامة:** خلال + مدة أو عهد (خلال حكمه، خلال نصف القرن الماضي، خلال ذلك اليوم)
- **الأصل:** during, throughout
- ✗ وغزا مدنًا خلال وقت حكمه → ✓ وافتتح في إمارته مدائن
- ✗ يقولها في الصباح فيموت خلال ذلك اليوم → ✓ يقولها حين يصبح فيموت من يومه
- **الحكم:** 🟡 «خلال» هنا ترجمة during؛ والعربية تقول «في» + المدة، أو «على عهده»، أو «من يومه»
- **المصدر:** ص 177، 188، 216

### SYN-030 · كلّما … كلّما

- **الأصل:** the more … the more / plus … plus
- ✗ كلّما اجتهدتَ كلّما نجحت → ✓ كلّما اجتهدتَ نجحت
- **الحكم:** 🔴 «كلّما» تدخل على الشرط وحده، وتكرارها في الجواب نقل للمقارنة المزدوجة

### SYN-031 · سوف لن
- **العلامة:** سوف لن، سوف لا
- **الأصل:** will not
- ✗ هم سوف لن يؤمنوا → ✓ لن يؤمنوا / لا يؤمنون
- ✗ عذابهم سوف لن يُخفَّف → ✓ فلا يُخفَّف عنهم العذاب

### SYN-032 · كان وما زال
- **العلامة:** كان وما زال، كانوا وما زالوا، كان ولا يزال، كانت وما تزال
- **الأصل:** was and still is
- ✗ كانوا وما زالوا يدورون في فلك السلطة → ✓ ما زالوا يدورون في فلك السلطة
- ✗ الموسيقى التي كانت، وما تزال، من أجل قضيتنا → ✓ الموسيقى التي ما زالت تنتصر لقضيتنا
- **الحكم:** 🟡 الإنجليزية تجمع الماضي والحاضر لتغطية المدة، و«ما زال» تدل وحدها على الاستمرار من الماضي؛ ظهر في نماذج المؤلف ولم يفرده بحكم
- **المصدر:** ص 178، 180

### SYN-033 · أو بعد النفي
- **العلامة:** لا / لن / لم + فعل + س أو ص
- **الأصل:** not … X or Y
- ✗ لن نترك رجلًا أو طفلًا → ✓ لن نترك رجلًا ولا طفلًا
- **الحكم:** 🟡 العربية تكرر «لا» لتنفي كل واحد (لا يغادر صغيرة ولا كبيرة)؛ لكن «أو» بعد النهي واردة في القرآن (ولا تطع منهم آثمًا أو كفورًا)، فهو ترجيح لا تخطئة
- **المصدر:** ص 52

### SYN-034 · أو في التسوية
- **العلامة:** فعل + أو لم + فعل؛ … أو لا (بمعنى سواءً)
- **الأصل:** whether … or not
- ✗ سأذهب جاء أو لم يجئ → ✓ سأذهب أجاء أم لم يجئ
- ✗ إذا حذّرتهم أو لا فلن يؤمنوا → ✓ سواءٌ عليهم أأنذرتهم أم لم تنذرهم لا يؤمنون
- **الحكم:** 🟡 الجادّة في التسوية الهمزة و«أم»؛ عدّ المؤلف «أو» فيها من أثر الترجمة مع وقوعها عند بعض القدماء
- **المصدر:** ص 53، 60

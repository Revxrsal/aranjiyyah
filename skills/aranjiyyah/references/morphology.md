# الصرف والصيغ

Morphology is the least calqued area. The damage here is mostly loss
(الإماتة) and crowding out (التغليب): Arabic forms with no English
counterpart (أفعل التفضيل, causative stems, تفاعل, استفعل, intensives,
participles, diminutives, the مفعول مطلق and the حال) give way to
helper-word paraphrases and to adverbs built on English ‎-ly. When a helper
word (أكثر، جعل، أصبح، بعضهم بعضًا، كثيرًا، بشكل، يبدو) does the job of a
derived form, suggest the derived form. Ordered by how often each shows up
in modern writing.

### MOR-001 · أكثر + تمييز مكان أفعل
- **العلامة:** أكثر / الأكثر + مصدر أو صفة من فعل ثلاثي (أكثر جمالًا، أكثر لطفًا، أكثر نبلًا، الأكثر علمًا، الأكثر رحمة)
- **الأصل:** more X / the most X
- ✗ هي أكثر جمالًا مني → ✓ هي أجمل مني
- ✗ الأكثر رحمة بأمتي → ✓ أرحم أمتي بأمتي
- ✗ هذا أكثر نبلًا وأكثر نزاهة → ✓ هذا أكرم وأنزه
- **الحكم:** 🔴 «أفعل» يُصاغ من الثلاثي مباشرة، والإنجليزية تُلحق more لأن صفاتها لا تتصرف
- **الاستثناء:** «أكثر / أشدّ» + تمييز هو الطريق لما لا يُصاغ منه أفعل (أكثر استعدادًا، أشدّ حمرة).
- **المصدر:** ص 64، 154

### MOR-002 · جعله + مضارع مكان التعدية
- **العلامة:** جعله / جعلها / جعلني + مضارع (يضحك، يبكي، ينام، يموت، يخرج، ينسى، يشعر، يركعون)؛ منحه الحياة؛ حوّله إلى (دين)
- **الأصل:** make him laugh / sleep; give life to; convert him to
- ✗ جعله يضحك وجعله يبكي → ✓ أضحكه وأبكاه
- ✗ منحكم الحياة ثم سيجعلكم تموتون → ✓ أحياكم ثم يميتكم
- ✗ زعموا أنها حوّلته إلى المسيحية → ✓ زعموا أنها نصّرته
- **الحكم:** 🔴 العربية تعدّي الفعل بالهمزة أو التضعيف، وتشتق الفعل من الاسم (نصّره، هوّده)، أو تقول «حمله على» و«أخذه بـ»؛ والإنجليزية تحتاج make + فعل
- **الاستثناء:** «جعل يفعل» بمعنى شرع سليمة (جعل يبكي).
- **المصدر:** ص 60، 64، 187–188

### MOR-003 · أصبح / صار / كان + صفة مكان الفعل
- **العلامة:** أصبح / صار / كان / يكون + صفة أو اسم فاعل لها فعل من جذرها (قاسيًا، فخورين، قادرًا، مدركين، غاضبًا، مسيحيًّا)؛ جُعل + أفعل (جُعل أقوى)
- **الأصل:** become hard, be proud of, be able to, became aware, be made stronger
- ✗ أصبح قلبه قاسيًا → ✓ قسا قلبه
- ✗ يحقّ لنا أن نكون فخورين بهذا الكتاب → ✓ يحقّ لنا أن نفخر بهذا الكتاب
- ✗ وأصبحوا مدركين للباب → ✓ وفطنوا للباب
- **الحكم:** 🔴 إذا أُريد حدث أو تحوّل فالفعل أخصر وأعرب (قسا، فخر، فطن، سخط، تنصّر، قوي)، والكلام اليومي لا يزال يقوله
- **الاستثناء:** «كان + صفة» لوصف ثابت سليمة (كان كريمًا). هذا الحدّ مستنبط من عبارة المؤلف لا منصوص، فما اشتبه فهو 🟡.
- **المصدر:** ص 62–63، 124، 187، 189، 191

### MOR-004 · بشكل / بصورة / بطريقة + صفة
- **العلامة:** بشكل + صفة (بشكل عام، بشكل سلبي، بشكل قاطع، بشكل مفاجئ، بشكل كامل)، بصورة + صفة (بصورة عامة، بصورة بارزة)، بطريقة + صفة، بصفة عامة
- **الأصل:** ‎-ly adverbs: generally, negatively, firmly, suddenly
- ✗ قرّرتُ بشكل قاطع أن أقول الحقيقة → ✓ فأجمعتُ صدقه
- ✗ وبشكل مفاجئ وصلتني رسالة منه → ✓ وإذا رقعة منه قد جاءتني
- ✗ عواطف الناس، بصورة عامة، … → ✓ وعامّة الناس عواطفهم … / والناس في الجملة …
- **الحكم:** 🟡 الإنجليزية تصوغ الحال من الصفة بـ ‎-ly، فصار «بشكل» قالبًا لكل ظرف؛ والعربية تؤدي ذلك بالفعل نفسه (أجمع)، أو بالحال، أو بالمفعول المطلق، أو بإذا الفجائية، أو بظرف قديم (عامّةً، فجأةً، في الجملة)
- **المصدر:** ص 66، 71، 83، 125، 172، 210

### MOR-005 · يوميًّا / أسبوعيًّا / سنويًّا
- **العلامة:** يوميًّا، أسبوعيًّا، شهريًّا، سنويًّا، ساعيًّا؛ معارك يومية
- **الأصل:** daily, weekly, monthly, yearly
- ✗ يزورنا أسبوعيًّا → ✓ يزورنا كل أسبوع
- ✗ ويتلقّى الروم الإمدادات يوميًّا → ✓ وفي كل يوم يزيد مددهم
- **الحكم:** 🔴 نسخ لظروف الإنجليزية المشتقة من اسم الزمن؛ والعربية تقول «كل يوم / في كل يوم / كل سنة»
- **المصدر:** ص 206، 210

### MOR-006 · الظرف المنسوب للجهة (عسكريًّا، شخصيًّا)
- **العلامة:** نسبة + تنوين نصب ظرفًا للجهة: عسكريًّا، دبلوماسيًّا، حضاريًّا، رسميًّا، دينيًّا، شخصيًّا، افتراضيًّا، كتابيًّا، تحديدًا، عمومًا
- **الأصل:** militarily, officially, personally, hypothetically (‎-ally)
- ✗ شرعت في استرداد المغرب حضاريًّا ودبلوماسيًّا قبل أن تسترجعه عسكريًّا → ✓ بدأت تستردّ المغرب بالثقافة والسياسة قبل أن تستردّه بالسلاح
- ✗ وحتى لو حدث ذلك افتراضيًّا كاستثناء نادر → ✓ وإن ندر ذلك في صورة مفروضة
- ✗ أمر يستحق الثناء دينيًّا → ✓ أمر مستحبّ شرعًا
- **الحكم:** 🟡 كثرتها نقل لـ ‎-ally؛ والعربية تذكر الجهة بالباء أو «في»، أو بفعل (فُرض، ندر)؛ وبعضها قديم مقبول (شرعًا، عرفًا، لغةً)
- **المصدر:** ص 134، 165، 169، 172، 177، 217

### MOR-007 · يبدو + صفة / بدا لي صعبًا
- **العلامة:** يبدو / بدا / تبدو + صفة (يبدو لئيمًا، بدا سهلًا، تبدو غير مهمة)؛ بدا لي، يبدو لي، يبدو في عيني؛ مما يجعله يبدو
- **الأصل:** seem, appear, look
- ✗ بدا لي الأمر صعبًا → ✓ استصعبتُ الأمر
- ✗ هل بدا لكم العهد طويلًا جدًّا؟ → ✓ أفطال عليكم العهد؟
- ✗ يمنعهم مما يجعله يبدو لئيمًا → ✓ يمنعهم فيلؤم
- **الحكم:** 🟡 الإنجليزية تمرّر الصفة المدرَكة عبر seem، والعربية تصرّح بها بالفعل، أو بـ«استفعل» لمعنى «وجدته كذا» (استصعب، استسهل، استحسن، استقبح)، أو بفعل ظنّ (أحسب، أرى)؛ «يبدو» عربية، فعلّمها إذا تكاثرت أو صلح مكانها فعل
- **المصدر:** ص 154، 156، 160

### MOR-008 · مع بعضهم البعض بعد تفاعل
- **العلامة:** تفاعل أو افتعل + مع بعضهم (البعض)؛ مع بعضنا البعض؛ اتحدوا مع بعضهم
- **الأصل:** with each other
- ✗ تحالفوا مع بعضهم البعض ضدّ الإسلام → ✓ تحالفوا على الإسلام
- ✗ يتعاونون مع بعضهم البعض → ✓ يتعاونون
- ✗ واتحدوا مع بعضهم لقتله → ✓ واجتمعوا على قتله
- **الحكم:** 🔴 صيغة تفاعل تحمل معنى المشاركة، فالزيادة حشو، و«مع» ترجمة with
- **المصدر:** ص 65، 187

### MOR-009 · بعضهم بعضًا / أحدهم الآخر مكان تفاعل
- **العلامة:** بعضهم بعضًا، أحدهم الآخر، بشكل متبادل، بالتبادل
- **الأصل:** each other, one another, mutually
- ✗ ضرب بعضهم بعضًا → ✓ تضاربوا
- ✗ أحبّ أحدهم الآخر → ✓ تحابّوا
- ✗ ساعد بعضنا بعضًا → ✓ تعاونّا
- **الحكم:** 🟡 «بعضهم بعضًا» واردة في العربية، لكن تفاعل هي الجادّة؛ و«أحدهم الآخر» و«بشكل متبادل» أبعد عنها
- **المصدر:** ص 65

### MOR-010 · كن / لا تكن + صفة مكان الأمر
- **العلامة:** كن / كوني / كونوا / لا تكن / لا تكونوا + صفة
- **الأصل:** be patient, be honest with, don't be late
- ✗ كن صابرًا → ✓ اصبر
- ✗ كن صادقًا مع صاحبك → ✓ اصدق صاحبك
- ✗ لا تكن متأخرًا → ✓ لا تتأخر
- **الحكم:** 🟡 المطلوب فعلٌ لا صفة ثابتة، فالأمر بالفعل نفسه أعرب
- **الاستثناء:** «كونوا» + وصف ثابت أو اسم واردة في القرآن (كونوا قوّامين بالقسط، كونوا أنصار الله)، فلا تخطّئ البنية نفسها.
- **المصدر:** ص 63

### MOR-011 · ظرف مكان صيغة المبالغة
- **العلامة:** فعل + كثيرًا / باستمرار / بشكل معتاد / بإفراط؛ الذي يفعل كثيرًا
- **الأصل:** constantly, habitually, excessively
- ✗ الذي يحلف كثيرًا → ✓ حلّاف
- ✗ يكذب كثيرًا → ✓ كذوب
- ✗ هو ينقل الأسرار كثيرًا → ✓ هو نقّال للسرّ
- **الحكم:** 🟡 للعربية أبنية مبالغة (فعّال، فعول، مِفعال) لا مقابل لها في الإنجليزية، فهُجرت في الكتابة وبقيت في الكلام
- **المصدر:** ص 66

### MOR-012 · جملة فعلية مكان اسم الفاعل
- **العلامة:** لن + مضارع، الذي + فعل، سـ + فعل، حيث يصلح اسم الفاعل أو المفعول خبرًا
- **الأصل:** will / won't + verb; will be held responsible
- ✗ لن تتبع قبلتهم → ✓ وما أنت بتابعٍ قبلتهم
- ✗ لن تعجزوا الله، والله سوف يخزي الكافرين → ✓ أنكم غير معجزي الله وأن الله مخزي الكافرين
- ✗ يعلم أنه سوف يتمّ تحميله المسؤولية → ✓ يعلم أنه مسؤول
- **الحكم:** 🟡 اسم الفاعل والمفعول خبرًا يحملان الحدث والاستقبال، والإنجليزية تلجأ إلى الفعل وأداة الزمن؛ اقترحه ولا تعدّ الفعل خطأ
- **المصدر:** ص 66، 151

### MOR-013 · غير قابل لـ + مصدر / الغير + صفة
- **العلامة:** غير قابل / قابلة + لل + مصدر (غير قابل للوصف، غير قابل للتطبيق)؛ الغير + صفة أو مفعول (الغير مبرّر، الغير شرعي)
- **الأصل:** un-X-able; unjustified, non-
- ✗ حياة ذات وفرة غير قابلة للوصف → ✓ شيء كثير لا يوصف
- ✗ الاعتداء الغير مبرّر → ✓ البغي بغير الحق
- **الحكم:** 🟡 بناء للسابقة un- واللاحقة ‎-able؛ والعربية تنفي الفعل المبني للمجهول (لا يوصف، لا يُطبَّق) أو تقول «بغير حقّ»؛ ظهر في الترجمات العكسية
- **المصدر:** ص 99، 186

### MOR-014 · صغير / قليل مكان التصغير
- **العلامة:** صغير / صغيرة / قليل + اسم يُصغَّر عادة (ولد صغير، قطعة لحم صغيرة، غنم قليلة)
- **الأصل:** little, small, a few
- ✗ ولد صغير → ✓ وُلَيد
- ✗ قطعة لحم صغيرة → ✓ لُحَيمة
- **الحكم:** 🟡 أضعف قواعد الباب: اقترح التصغير حيث يجري طبيعيًا في السياق، ولا تعلّم كل «صغير»
- **المصدر:** ص 67
